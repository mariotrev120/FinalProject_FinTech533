Defined-Risk Volatility-Risk-Premium Harvesting

FinTech 533 capstone · Mario Treviño · Duke MEng FinTech

The strategy in one sentence

A 4-instrument cross-asset put-credit-spread basket (AAPL, MSFT, WMT, GLD) with a 3-layer halt framework, sized at 16-delta short strikes with weekly Monday entries, harvesting the volatility risk premium across single-stock idiosyncratic vol and commodity-ETF cross-asset vol simultaneously.

Headline result

Excess Sharpe +0.359 over OOS 2018-2024, beating the v1.5 single-name SPX put-only baseline (+0.286) by 0.073 with cross-asset diversification and 2× the trade sample.

Metric Value
Sharpe (excess of risk-free) +0.359
Risk-free baseline (avg IRX 2018-2024) 2.33%
Annualized return +2.41%
Max drawdown over 7 years -0.13%
Trades total 437
DSR (PSR) 1.0000 ≥ 0.95 ✓
PBO via CSCV 0.0402 ≤ 0.30 ✓

Both pre-committed acceptance gates pass. See Results for the full breakdown and Pre-commitments for the locked methodology.

What’s behind the number

  • 4-instrument cross-asset basket, three single-stocks (AAPL, MSFT, WMT) for idiosyncratic short-vol exposure plus GLD for commodity-vol exposure. Selected from a 12-instrument tested universe; selection bias corrected via DSR (N̂=9 implied independent trials).
  • 3-layer halt framework, Layer 1 hard halts on extreme single-day SPX moves, Layer 4 trailing-90-day drawdown gate, Layer 5 vol-regime auto-resume with 60-day time fallback.
  • Per-trade defined risk, 16-delta short put, 5-pt long-put protection, weekly Monday entries, gap-aware exit fills, VIX-conditional slippage model.
  • Exogenous-factor inputs, VIX/VIX3M/VVIX/SKEW for regime classification, IRX for risk-free baseline + cash accrual, HYG-LQD spread + rolling SPY-Treasury correlation for stress detection. See Mechanics for the full list.
  • Honest aggregation, book Sharpe computed from the equal-weighted aggregate equity curve, not from per-instrument Sharpe averaging. Cross-instrument correlation 0.26 (low) drives the diversification benefit.

Pre-commitment-driven methodology

Every parameter, threshold, and acceptance criterion was locked in version-controlled pre-commitment documents before the OOS backtest ran. Methodology amendments after pre-commitment are logged with date and reason. See Pre-commitments.

Live-monitoring framework

The strategy ships with a Hoeffding trader-application bound that quantifies, in real time, the probability the underlying win-rate has shifted away from the pre-committed baseline. Threshold semantics (50% / 25% / 10% probability bound) trigger reduce-size, freeze, and shut-down actions respectively. See Live Monitoring for the full framework and worked example on the headline basket.

What was tested but not used

The headline is one of five baskets tested. The four others (SPX-only put-credit-spread, ETF-3 cluster, full 6-instrument book, iron condor variants on the 3-instrument cluster) underperformed the v1.5 anchor. They are reported transparently in the Ablations page, the iron condor variant is particularly informative: adding the call wing systematically lost in the 2018-2024 trending-equity regime.

Reproducibility

Single-command reproduction from a fresh checkout:

git clone <repo>
cd FinalProject_FinTech533
python -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
PYTHONPATH=. python scripts/convert_optionmetrics_to_parquet.py   # one-time, ~80s
PYTHONPATH=. python scripts/run_multi_instrument_vrp.py \
    --tickers AAPL MSFT WMT GLD \
    --mode halts_only --no-ic \
    --total-capital 200000

SEED = 42 is consumed by every stochastic component. Two runs of the same commit produce identical equity curves to floating-point precision. See Reproducibility.

## What's behind the number

- **4-instrument cross-asset basket**, three single-stocks (AAPL, MSFT, WMT) for idiosyncratic short-vol exposure plus GLD for commodity-vol exposure. Selected from a 12-instrument tested universe; selection bias corrected via DSR (N̂=9 implied independent trials).

- **Per-trade defined risk**, 16-delta short put, 5-pt long-put protection, weekly Monday entries, gap-aware exit fills, VIX-conditional slippage model.
- **Exogenous-factor inputs**, VIX/VIX3M/VVIX/SKEW for regime classification, IRX for risk-free baseline + cash accrual, HYG-LQD spread + rolling SPY-Treasury correlation for stress detection. See [Mechanics](mechanics.qmd) for the full list.
- **Honest aggregation**, book Sharpe computed from the equal-weighted aggregate equity curve, not from per-instrument Sharpe averaging. Cross-instrument correlation 0.26 (low) drives the diversification benefit.
