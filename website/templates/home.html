ML Entry Gate

XGBoost Classifier

A gradient-boosted classifier trained on 16 exogenous market features predicts whether a spread opened today will close at profit target. Entry is gated at a calibrated probability threshold of p ≥ 0.55.

The model is trained in an expanding-window walk-forward loop (annual refit, nested cross-validation with Optuna hyperparameter search, isotonic calibration). An elastic-net logistic benchmark provides a lower bound.

Five-Layer Halt Framework

The halt framework operates independently of the ML gate, providing mechanical circuit breakers that prevent new entries during adverse regimes. Layers 2–5 are "soft halts" — existing positions remain open; only new entries are blocked.

Layer 1 · Hard Halt
Extreme Vol Spike
VIX day-over-day ≥ 50%, SPX ±6% intraday, or VIX exceeds VIX3M by ≥ 3 pts. Closes all positions immediately; blocks new entries until reset.
Layer 2 · Soft Halt
ML Confidence Drought
Five consecutive trading days with model probability < 0.55. New entries blocked; existing positions managed normally.
Layer 3 · Hoeffding Halt
Statistical Win-Rate Deviation
Hoeffding bound test flags realized win rate significantly below 60% historical target. Requires minimum trade count before activating.
Layer 4 · Drawdown Halt
Portfolio Drawdown Limit
Portfolio NAV drawdown exceeds configurable threshold from peak equity. Blocks new entries; resumes on partial recovery.
Layer 5 · Auto-Resume Gate
Four-Condition Conjunction
All four must hold simultaneously: VIX < 25, VIX in contango, model p ≥ 0.55, SPX above 200-day MA. Any single failure keeps the halt active.

Position Sizing & Friction Model

Sizing Formula

Contract count is derived from Quarter-Kelly multiplied by a VIX vol scalar (15 ÷ VIX) and a stress multiplier (0.5× when SPY–TLT correlation > 0.50). The result is hard-capped at 1% of portfolio equity to prevent oversizing in low-vol environments.

n = min(¼K · (15/VIX) · stress_mult, floor(0.01·NAV / margin))

Realistic Friction

Four VIX-tiered bid-ask slippage buckets (0.30–1.00 per side), plus per-leg commission (min $1.30), financing cost on margin, and Section 1256 tax treatment (60% LTCG / 40% STCG on all XSP options regardless of holding period).

Ablation Study Design

Four modes isolate the contribution of each component. All modes share the same universe, position sizing, and friction model — only the entry gate and halt framework differ.

Vestal Rubric Questions

How would you monitor live performance?
Daily NAV reconciliation against IBKR position ledger; Hoeffding bound on rolling win rate (alerts if p-value < 0.05 vs. 60% baseline); VIX regime tracker to detect distribution shift between training and live environments; ML model score histogram drift (KL divergence alert); hard halt auto-triggers as circuit breakers. This dashboard's Results tab provides the primary monitoring surface.
How do you quantify strategy failure?
Strategy failure is declared if: (1) OOS Sharpe < 0.5 for any 12-month rolling window, (2) max drawdown exceeds 25% of peak NAV, (3) realized win rate falls below 45% over any 40-trade window, or (4) the ML gate's Brier score exceeds 0.30 (no better than naive baseline). The ablation study quantifies which components are responsible for underperformance if triggered.
