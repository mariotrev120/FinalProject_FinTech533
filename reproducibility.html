Reproducibility

Two runs of the same commit + the same data + the same SEED = 42 produce identical equity curves to floating-point precision. This page documents how to reproduce every number in the results page from a fresh checkout.

Environment

  • Python 3.12+ on Linux/macOS/WSL (tested on WSL Ubuntu 22.04)
  • ~16 GB RAM (4–6 GB working set; SPX parquet is the largest single load at ~750 MB on disk)
  • ~3 GB disk free for per-ticker parquets

One-time setup

git clone <repo-url> FinTech533_capstone
cd FinTech533_capstone
git checkout mario/data-pipeline   # not yet merged to main

python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

One-time data conversion

The OptionMetrics CSV (strat2.2.csv.gz, ~2.4 GB compressed, 68.4M rows) is converted to per-ticker parquets via DuckDB streaming. Without this step, loading the CSV via pandas exhausts WSL memory and crashes the session.

PYTHONPATH=. python scripts/convert_optionmetrics_to_parquet.py

Expected runtime: ~80 seconds. Output: 14 parquets in data/processed/options_by_ticker/{TICKER}.parquet, parity-checked against original CSV row counts. Idempotent (re-running with parquets in place is a no-op unless --force).

Reproduce headline results

# 1. Verify parquet conversion (52 parity tests)
PYTHONPATH=. pytest tests/test_optionmetrics_parquet_loader.py -v

# 2. Run all logic tests (no data load required)
PYTHONPATH=. pytest tests/ --ignore=tests/test_optionmetrics_parquet_loader.py -q
# Expected: 92/92 PASS

# 3. SPX halts_only diagnostic (sanity check on Layer 4 fix)
PYTHONPATH=. python scripts/diagnose_spx_halts_only.py
# Expected: Sharpe 0.497, 12 distinct halt periods, max 92 days

# 4. Multi-instrument NAKED runner (5 VRP tickers, ~10 min)
PYTHONPATH=. python scripts/run_multi_instrument_vrp.py --mode naked

# 5. Multi-instrument halts_only runner (5 VRP tickers, ~10 min)
PYTHONPATH=. python scripts/run_multi_instrument_vrp.py --mode halts_only

# 6. ML head training (Heads 1, 2, 3, Heads 1/3 reuse the multi-instrument output;
#    Head 2 is independent and uses features.parquet)
PYTHONPATH=. python scripts/run_head2_regime_stress.py
PYTHONPATH=. python scripts/train_head1_per_instrument.py
PYTHONPATH=. python scripts/train_head3_per_instrument.py

# 7. Hoeffding live-monitoring backtrace
PYTHONPATH=. python scripts/hoeffding_monitor.py

Data Sources

The strategy reads from three external data providers, all snapshotted to local parquet files at commit time. No live network connections occur during a backtest.

1. OptionMetrics IvyDB (option chains)

File: strat2.2.csv.gz (2.4 GB compressed, 68.4M rows) → split via scripts/convert_optionmetrics_to_parquet.py into per-ticker parquets at data/processed/options_by_ticker/{TICKER}.parquet.

Provides: daily option chains (date, exdate, cp_flag, strike, best_bid, best_offer, impl_volatility, delta, gamma, vega, theta, volume, open_interest) for 12 tickers spanning 2012-2025. Used by the engine to price entries and exits at real chain quotes (not BS-pricer fallback) wherever available.

2. WRDS OptionMetrics IvyDB Securities (per-ticker underlying OHLC)

File: wheelstrat_data.gz (querying WRDS via Duke subscription) → split via scripts/convert_wheelstrat_data.py into per-ticker parquets at data/raw/{TICKER}.parquet.

Provides: daily underlying OHLC (open, high, low, close, volume, return, cfadj) for the 4 headline-basket tickers (AAPL, MSFT, WMT, GLD) and 6 other instruments tested in the ablation matrix. Spans 2012-01-03 to 2025-08-29. Same secid system as the OptionMetrics chains, ensuring clean joins between underlying spot and option chains for the same security on the same date. Daily closes match published exchange records on spot-checked reference dates (e.g., AAPL 2018-04-16 = $175.82).

3. Interactive Brokers TWS feed snapshot (exogenous macro factors)

Files: data/raw/{VIX,VIX3M,VVIX,SKEW,IRX,TNX,HYG,LQD,SPY,SPX}.parquet. Snapshotted from the Interactive Brokers TWS market-data feed and frozen to local parquet at commit time. No live TWS connection is needed at backtest time.

Provides: macro / regime indicators (CBOE volatility indices, FRED Treasury yields, ETF macro tape, SPX bars for the market-wide gap-skip and Layer 1 hard halt). Spans 2011-05-05 to 2026-04-30 across the various series.

Determinism

  • SEED = 42 (in src/config.py) consumed by:
    • XGBoost random_state for every fit
    • sklearn IsotonicRegression (no randomness, but LogisticRegression for Platt: solver="lbfgs" is deterministic)
    • Block-bootstrap CI sampling
    • HMM Baum-Welch (each of 20 random inits uses seed + i)
  • No time()-based randomness in the codebase
  • No floating-point reduction non-determinism (we don’t use numpy.einsum_path optimization or BLAS-threaded sums)

Verification: run any backtest twice on the same machine, save the equity curves, diff them, they should be byte-identical.

What’s NOT included

  • Real broker fee schedules (we use pre-committed $0.65/contract slippage proxy)
  • Intraday tick data (HAR-RV uses daily close-to-close; this is a documented limitation)
  • Live trading deployment scripts (the strategy is paper-tested only)
  • The full sensitivity grid (729 trials), this is a separate offline computation; instructions in scripts/run_sensitivity_grid.py (TBD)
